# Screenshots

This folder contains screenshots for the README documentation.

## Required Screenshots

Please capture the following screenshots at **1280x800** resolution (or similar 16:10 aspect ratio):

### 1. `homepage.png`
- The main dashboard/landing page
- Shows the welcome hero section with teacher
- Progress stats visible
- Light mode preferred

### 2. `conversations.png`
- The conversations page showing multiple scenarios
- Include both locked and unlocked conversation cards
- Shows the progression system

### 3. `vocabulary.png`
- The vocabulary browser page
- Show category cards or word list
- Multiple vocabulary items visible

### 4. `grammar.png`
- A grammar lesson in progress
- Show lesson content and/or an exercise
- Visible feedback or progress indicator

### 5. `flashcards.png`
- The flashcard practice interface
- Show a card (flipped or unflipped)
- Session stats visible if possible

### 6. `practice.png`
- The numbers/time drill page
- Show the drill selection or an active drill
- Include the teacher bubble

## Tips for Good Screenshots

1. **Use a clean browser window** - Hide bookmarks bar and extensions
2. **Consistent sizing** - Keep all screenshots the same dimensions
3. **Light mode recommended** - Better visibility in documentation
4. **Show populated state** - Complete a few exercises first so progress shows
5. **Crop browser chrome** - Or use a screenshot tool that captures just the content
