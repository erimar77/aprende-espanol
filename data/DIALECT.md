# Spanish Dialect Target

All Spanish content in this directory targets **Latin American Spanish, Peru-leaning**.

## Rules

- **Tuteo only.** Use `tú` (informal you) and `usted` (formal you). No `vos` / voseo forms.
- **No `vosotros`.** Plural-you is always `ustedes`, whether informal or formal.
  - Conjugation tables: 5 forms only (`yo`, `tú`, `él/ella/usted`, `nosotros`, `ellos/ustedes`). No `vosotros` column.
- **Currency:** soles (`S/.`) in Peru-framed scenes; only use `euros` / `€` when the scene is explicitly Spain.
- **Food/dishes:** Peruvian by default in Peru-framed scenes (`ají de gallina`, `lomo saltado`, `causa`, `arroz con pollo`, `pisco sour`, `chilcano`). Spain-only items (`paella`, `tortilla española`, `jamón ibérico`, `sangría`, `tapas`) should appear only in Spain-framed scenes.
- **Vocabulary swaps** when the scene is Peru/Latin America:
  - `coger` → `tomar` / `agarrar`
  - `ordenador` → `computadora`
  - `móvil` → `celular`
  - `quedáis` / `quedáis con` → `se juntan` / `se reúnen` / `nos vemos`
  - `patata` → `papa`
  - `zumo` → `jugo`
  - `ahora mismo` is fine; `al toque` is regionally Peruvian and welcome where appropriate.

## Accents

Always write written accents (tildes). Common ones that get dropped:

- `está` (verb) vs `esta` (this) — `está` ≠ `esta`
- `sé` (I know) vs `se` (reflexive) — `sé` ≠ `se`
- `tú` (subject pronoun "you") vs `tu` (possessive "your") — `tú` ≠ `tu`
- `él` (he) vs `el` (the) — `él` ≠ `el`
- `más` (more) vs `mas` (but, literary) — almost always `más`
- All preterite `-í` and `-ió` endings on `-er`/`-ir` verbs: `escribí`, `escribió`, `pedí`, `pidió`, etc.
- All interrogatives at sentence start: open with `¿` and accent the question word (`¿Cómo`, `¿Dónde`, `¿Cuándo`, `¿Qué`, `¿Quién`, `¿Cuál`, `¿Por qué`).
- All exclamations at sentence start: open with `¡` and accent the exclamation word (`¡Qué tal!`, `¡Hola!`).
- Geography: `México`, `España`, `Perú`, `Bogotá`, `Panamá`, `Río de la Plata`.
- Common nouns: `película`, `café`, `música`, `María`, `mañana`, `médico`, `frío`, `adiós`, `melón`, `televisión`, `página`.

## When to deviate

If you intentionally write a scene set in Spain (e.g., Granada tapas), use Peninsular Spanish *consistently* in that scene — Spain vocabulary, euros, `vosotros` if it fits. Flag the scene with a clear `country: 'spain'` or in-context cultural note so future contributors know it's deliberate.
